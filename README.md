# Nurse Recovery Kit 🩷
React Router v7 + Tailwind v4 + shadcn-style components (Button, Card, Badge).

```bash
npm install
npm run dev      # http://localhost:5173
```

- Put your voice note at `public/kaya-mo-yan.mp3`
- Edit `PLAYLIST_URL` and the message lists in `app/routes/home.tsx`
- Colors and fonts live in `app/app.css` (`@theme`)

Want the official shadcn CLI versions later? Run `npx shadcn@latest init` and `npx shadcn@latest add button card badge sonner drawer`.
